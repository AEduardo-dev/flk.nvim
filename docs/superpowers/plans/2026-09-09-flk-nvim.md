# flk-nvim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `nix-develop`/`devenv`/`riff` backends of this plugin with a single flk backend that enters an flk profile's environment from inside a running Neovim session.

**Architecture:** Rather than parsing `nix print-dev-env --json` and reconstructing the shellHook's effects in Lua, run `nix develop … -c env -0` and let nix execute the real shellHook in a real shell. Diff the resulting environment against Neovim's own and apply the delta, recording prior values so it can be reversed. Profile discovery, the default profile, and the profile cache all come from the flk project's `.flk/` directory, mirroring `flk/src/commands/profile_cache.rs` and `flk/src/commands/hook.rs`.

**Tech Stack:** Lua (LuaJIT, as shipped in Neovim), Neovim 0.10+ stdlib (`vim.system`, `vim.uv`, `vim.fs`), nix. No external Lua dependencies — tests run under `nvim --headless -l` with a hand-rolled harness, since this plugin has no test tooling today and a nixvim consumer should not need luarocks.

**Spec:** `docs/superpowers/specs/2026-09-09-flk-nvim-design.md`

**Reference source (read-only, for mirroring behavior):** the flk repo at `../flk` — specifically `src/commands/profile_cache.rs`, `src/commands/hook.rs`, `src/commands/activate.rs`.

## File Structure

Created:

| File | Responsibility |
|---|---|
| `lua/flk/project.lua` | Locate the flk project root, validate profile names, read `defaultProfile`, list profile files |
| `lua/flk/cache.lua` | Profile cache paths and freshness — mirrors `profile_cache.rs` |
| `lua/flk/env.lua` | Parse `env -0`, diff against a baseline, apply and reverse |
| `lua/flk/init.lua` | Public API and nix orchestration |
| `plugin/flk.lua` | `:Flk` and `:FlkOff` with completion |
| `tests/helpers.lua` | Assertions and temp-directory fixtures |
| `tests/run.lua` | Test runner |
| `tests/*_spec.lua` | One spec file per module |

Deleted: `lua/nix-develop/init.lua`, `plugin/nix-develop.lua`, `doc/nix-develop.txt`.

Modified: `gen-docs`, `README.md`.

**Boundary note:** `env.lua` never calls nix and `project.lua`/`cache.lua` never touch the environment. All process spawning lives in `init.lua`. This keeps every module with real logic testable without nix installed.

local M = {}

---Assert two values are equal, with a readable message on failure.
function M.eq(actual, expected, msg)
  if actual ~= expected then
    error(
      string.format(
        "%sexpected %s, got %s",
        msg and (msg .. ": ") or "",
        vim.inspect(expected),
        vim.inspect(actual)
      ),
      2
    )
  end
end

---Assert two tables are equal by deep comparison.
function M.same(actual, expected, msg)
  if not vim.deep_equal(actual, expected) then
    error(
      string.format(
        "%sexpected %s, got %s",
        msg and (msg .. ": ") or "",
        vim.inspect(expected),
        vim.inspect(actual)
      ),
      2
    )
  end
end

---Assert a value is truthy.
function M.ok(value, msg)
  if not value then
    error(msg or "expected a truthy value", 2)
  end
end

---Assert a value is falsy.
function M.falsy(value, msg)
  if value then
    error(
      string.format("%sexpected falsy, got %s", msg and (msg .. ": ") or "", vim.inspect(value)),
      2
    )
  end
end

---Create a temp directory that is removed when the test run ends.
function M.tmpdir()
  local dir = vim.fn.tempname()
  vim.fn.mkdir(dir, "p")
  return dir
end

---Write `content` to `path`, creating parent directories as needed.
function M.write(path, content)
  vim.fn.mkdir(vim.fs.dirname(path), "p")
  local fd = assert(vim.uv.fs_open(path, "w", 420))
  assert(vim.uv.fs_write(fd, content))
  assert(vim.uv.fs_close(fd))
end

---Set a file's mtime to `seconds` (an absolute unix timestamp).
function M.set_mtime(path, seconds)
  assert(vim.uv.fs_utime(path, seconds, seconds))
end

return M
```

---Find the flk project root by walking up from `start` looking for `.flk/`.
---@param start? string Directory to start from (default: the cwd)
---@return string? root Absolute, symlink-resolved path, or nil if not found
function M.find_root(start)
  local from = start or vim.fn.getcwd()
  local found = vim.fs.find(".flk", {
    path = from,
    upward = true,
    type = "directory",
  })[1]

  if not found then
    return nil
  end

  return vim.fn.resolve(vim.fs.dirname(found))
end
```

---Read `defaultProfile` from `<root>/.flk/config.nix`.
---
---The file is flk-generated and simple, so a pattern is enough. A hand-edited
---config with unusual formatting will defeat it; callers should fall back to
---asking nix (`nix eval --raw .#defaultShell.<system>`).
---@param root string Project root
---@return string? profile
function M.default_profile(root)
  local path = root .. "/.flk/config.nix"
  local fd = vim.uv.fs_open(path, "r", 420)
  if not fd then
    return nil
  end

  local stat = vim.uv.fs_fstat(fd)
  local content = stat and vim.uv.fs_read(fd, stat.size, 0) or nil
  vim.uv.fs_close(fd)
  if not content then
    return nil
  end

  local profile = content:match('defaultProfile%s*=%s*"([^"]*)"')
  if not M.is_valid_profile(profile) then
    return nil
  end

  return profile
end

---List profile names from `<root>/.flk/profiles/*.nix`.
---
---Used for instant completion. It misses flk's generated profile
---combinations, which only nix can enumerate.
---@param root string Project root
---@return string[] names
function M.profile_files(root)
  local dir = root .. "/.flk/profiles"
  local handle = vim.uv.fs_scandir(dir)
  if not handle then
    return {}
  end

  local names = {}
  while true do
    local name, kind = vim.uv.fs_scandir_next(handle)
    if not name then
      break
    end
    if kind ~= "directory" and name:sub(-4) == ".nix" and name ~= "default.nix" then
      local profile = name:sub(1, -5)
      if M.is_valid_profile(profile) then
        table.insert(names, profile)
      end
    end
  end

  return names
end
```

---@mod flk.cache flk's per-profile nix profile cache
---
---Mirrors flk src/commands/profile_cache.rs so a profile warmed by the flk
---CLI activates instantly here, and vice versa.

local M = {}

-- The slim layout keeps the mkProject driver in a remote flake, so bumps
-- arrive through flake.lock rather than local .nix files.
local SLIM_INPUTS = { "flake.nix", "flake.lock", ".flk/config.nix", ".flk/pins.nix" }

local LEGACY_INPUTS = {
  "flake.nix",
  "flake.lock",
  ".flk/default.nix",
  ".flk/pins.nix",
  ".flk/overlays.nix",
}

---Path of the cached nix profile for `profile`.
---@param root string
---@param profile string
---@return string
function M.profile_path(root, profile)
  return root .. "/.flk/.nix-profile-" .. profile
end

---Path of the freshness stamp for `profile`.
---@param root string
---@param profile string
---@return string
function M.stamp_path(root, profile)
  return M.profile_path(root, profile) .. ".stamp"
end

---Absolute paths whose mtime decides whether the cache is stale.
---@param root string
---@param profile string
---@return string[]
function M.inputs(root, profile)
  local slim = vim.uv.fs_stat(root .. "/.flk/config.nix") ~= nil
  local base = slim and SLIM_INPUTS or LEGACY_INPUTS

  local paths = {}
  for _, relative in ipairs(base) do
    table.insert(paths, root .. "/" .. relative)
  end
  table.insert(paths, root .. "/.flk/profiles/" .. profile .. ".nix")

  return paths
end

return M
```

---Is `a` strictly newer than `b`? Both are `vim.uv` stat tables.
---@param a table
---@param b table
---@return boolean
local function newer_than(a, b)
  if a.mtime.sec ~= b.mtime.sec then
    return a.mtime.sec > b.mtime.sec
  end
  return (a.mtime.nsec or 0) > (b.mtime.nsec or 0)
end

---Can the cached profile be reused as-is?
---
---False whenever the cached profile or its stamp is missing, or any watched
---input is newer than the stamp. Inputs that do not exist are skipped, matching
---flk's `[ -e "$f" ] || continue`.
---@param root string
---@param profile string
---@return boolean
function M.is_fresh(root, profile)
  -- fs_stat follows symlinks, so a dangling profile link reads as absent —
  -- the same as flk's `[ -e ]` test.
  if not vim.uv.fs_stat(M.profile_path(root, profile)) then
    return false
  end

-- The environment as it stood before the first activation. Every diff is taken
-- against this, never against the currently-active environment, so repeated
-- switches cannot accumulate.
local baseline = nil

-- Names currently overridden by an active profile.
local applied = {}

local active = nil

---@param name string
---@param value string? nil unsets
local function set(name, value)
  if value == nil then
    vim.uv.os_unsetenv(name)
  else
    vim.uv.os_setenv(name, value)
  end
end

local function ensure_baseline()
  if not baseline then
    baseline = vim.fn.environ()
  end
  return baseline
end

---The PATH as it stood before any activation — flk's `FLK_ORIG_PATH`.
---
---Nix is always spawned with this PATH so a switch rebuilds from a clean
---baseline instead of layering onto the previous profile.
---@return string
function M.baseline_path()
  return ensure_baseline().PATH or ""
end

---The active profile name, or nil.
---@return string?
function M.active_profile()
  return active
end

---Apply a dev shell environment, replacing any previously applied one.
---@param vars table<string, string> Parsed `env -0` output
---@param ignored table<string, boolean> Names never to import
---@param profile string
function M.activate(vars, ignored, profile)
  local base = ensure_baseline()
  local changes = M.diff(base, vars, ignored)

  -- Anything the previous profile set that this one does not: back to baseline.
  for name in pairs(applied) do
    if changes[name] == nil then
      set(name, base[name])
      applied[name] = nil
    end
  end

  for name, value in pairs(changes) do
    set(name, value)
    applied[name] = true
  end

  active = profile
end

---Restore the environment as it stood before the first activation.
function M.deactivate()
  if not baseline then
    return
  end

  for name in pairs(applied) do
    set(name, baseline[name])
  end

  applied = {}
  active = nil
  baseline = nil
end

---Drop all state without touching the environment. Tests only.
function M.reset()
  baseline = nil
  applied = {}
  active = nil
end
```

local function notify(msg, level)

    vim.notify("flk: " .. msg, level or levels.INFO)

-- One activation at a time: a cold profile can take minutes, and two
-- concurrent runs would race on the environment and the cache stamp.
local running = false

---Pick the profile to activate.
---@param root string
---@param requested string? Explicit profile, if the user named one
---@return string? profile nil when nothing valid could be resolved
---@private
function M._resolve_profile(root, requested)
  if requested then
    return project.is_valid_profile(requested) and requested or nil
  end

  return env.active_profile() or project.default_profile(root)
end

---A human-readable list of the profiles this project defines.
---
---Filesystem only, so it is instant and works before nix has been asked. It
---misses flk's generated combinations, which is fine for an error message.
---@param root string
---@return string
---@private
function M._available_profiles(root)
  local names = project.profile_files(root)
  if #names == 0 then
    return "none"
  end

  table.sort(names)
  return table.concat(names, ", ")
end

---Record that the cache at `profile_path` is current as of now.
---@param root string
---@param profile string
local function touch_stamp(root, profile)
  if not vim.uv.fs_stat(cache.profile_path(root, profile)) then
    return
  end

  local stamp = cache.stamp_path(root, profile)
  local fd = vim.uv.fs_open(stamp, "w", 420)
  if fd then
    vim.uv.fs_close(fd)
  end
end

---Report a failed nix run with enough context to debug it.
---@param result table Result from vim.system
local function report_failure(result)
  local stderr = vim.trim(result.stderr or "")
  local lines = vim.split(stderr, "\n", { trimempty = true })
  local tail = {}
  for i = math.max(1, #lines - 5), #lines do
    table.insert(tail, lines[i])
  end

  local detail = #tail > 0 and ("\n" .. table.concat(tail, "\n")) or ""
  notify(string.format("nix exited with code %d%s", result.code, detail), levels.ERROR)
end

---Enter an flk profile's environment.
---
---With no argument this refreshes the active profile, or enters the project's
---default profile when nothing is active.
---@param requested string? Profile name
---@usage `require("flk").activate("docs")`
function M.activate(requested)
  if running then
    notify("an activation is already running", levels.WARN)
    return
  end

  local root = project.find_root()
  if not root then
    notify("not an flk project (no .flk/ directory found)", levels.ERROR)
    return
  end

  local profile = M._resolve_profile(root, requested)
  if not profile then
    if requested then
      notify(string.format("invalid profile name: %s", requested), levels.ERROR)
    else
      -- No nix-eval fallback here on purpose: resolution is synchronous, and
      -- naming the profiles the user can pass is more useful than a slow guess.
      notify(
        string.format(
          "no profile given and no defaultProfile in .flk/config.nix; available: %s",
          M._available_profiles(root)
        ),
        levels.ERROR
      )
    end
    return
  end

  local fresh = cache.is_fresh(root, profile)
  local baseline_path = env.baseline_path()

  notify(
    string.format("activating %s%s", profile, fresh and "" or " (building, this may take a while)")
  )

  running = true
  vim.system(M._command(root, profile, fresh), {
    cwd = root,
    text = true,
    -- Merged over Neovim's environment. Forcing PATH back to the baseline is
    -- what keeps a switch from layering onto the previous profile; see
    -- flk src/commands/hook.rs.
    env = {
      PATH = baseline_path,
      FLK_ORIG_PATH = baseline_path,
    },
  }, function(result)
    running = false

    if result.code ~= 0 then
      vim.schedule(function()
        report_failure(result)
      end)
      return
    end

    local vars = env.parse(result.stdout or "")
    if vim.tbl_isempty(vars) then
      notify("nix produced an empty environment; nothing changed", levels.ERROR)
      return
    end

    vim.schedule(function()
      env.activate(vars, M.ignored_variables, profile)
      if not fresh then
        touch_stamp(root, profile)
      end
      notify(string.format("entered %s", profile))
    end)
  end)
end

---Restore the environment as it stood before the first activation.
---@usage `require("flk").deactivate()`
function M.deactivate()
  if not env.active_profile() then
    notify("no active profile", levels.WARN)
    return
  end

  local profile = env.active_profile()
  env.deactivate()
  notify(string.format("left %s", profile))
end

---The active profile name, or nil.
---@return string?
---@usage `require("flk").status()`
function M.status()
  return env.active_profile()
end

```lua
-- Completion candidates for this session. Seeded from the profiles directory,
-- then replaced by the flake's devShells once nix has answered.
local profiles = nil
local profiles_pending = false

---Replace the cached completion candidates. Tests and the nix callback.
---@param names string[]
---@private
function M._set_profiles(names)
  profiles = vim.deepcopy(names)
  table.sort(profiles)
end

---Nix's name for the current system, e.g. "x86_64-linux" or "aarch64-darwin".
---@return string
local function nix_system()
  local uname = vim.uv.os_uname()

  -- Darwin reports "arm64"; nix calls it "aarch64".
  local arch = uname.machine == "arm64" and "aarch64" or uname.machine

  return arch .. "-" .. uname.sysname:lower()
end

---Ask nix for the flake's devShell names, including generated combinations.
---@param root string
local function refresh_profiles(root)
  if profiles_pending then
    return
  end
  profiles_pending = true

  vim.system({
    "nix",
    "eval",
    "--extra-experimental-features",
    "nix-command flakes",
    "--impure",
    "--json",
    string.format(".#devShells.%s", nix_system()),
    "--apply",
    "builtins.attrNames",
  }, { cwd = root, text = true }, function(result)
    profiles_pending = false
    if result.code ~= 0 then
      return
    end

    local ok, names = pcall(vim.json.decode, result.stdout or "")
    if ok and type(names) == "table" and #names > 0 then
      vim.schedule(function()
        M._set_profiles(names)
      end)
    end
  end)
end

---Completion candidates for `:Flk`.
---@param prefix string
---@return string[]
---@usage `require("flk").complete("do")`
function M.complete(prefix)
  if not profiles then
    local root = project.find_root()
    if not root then
      return {}
    end
    M._set_profiles(project.profile_files(root))
    refresh_profiles(root)
  end

  local matches = {}
  for _, name in ipairs(profiles) do
    if vim.startswith(name, prefix) then
      table.insert(matches, name)
    end
  end

  return matches
end

---All known profile names.
---@return string[]
---@usage `require("flk").profiles()`
function M.profiles()
  return M.complete("")
end
```

Note that `M.complete` uses `vim.startswith` rather than a Lua pattern match,
which is why a prefix of `-` returns no matches instead of raising: `-` is a
quantifier in Lua patterns, and `string.match` would have treated it as one.

## How it works

The environment is captured by running `nix develop … -c env -0` and diffing the
result against Neovim's own environment. Because nix executes the real shellHook
in a real shell, variables that flk emits from the hook — anything added with
`flk env add`, plus per-profile hook exports — arrive intact, which parsing
`nix print-dev-env --json` would miss.

flk's profile cache (`.flk/.nix-profile-<name>`) is shared with the flk CLI, so
a profile warmed in your shell activates instantly here.

## Requirements

- Neovim 0.10+
- nix with flakes enabled
- An flk project (a `.flk/` directory somewhere above the current directory)

The `flk` binary itself is not required: the plugin reads `.flk/` and drives nix
directly, which matters because Neovim usually starts outside the flk shell.

## Configuration

Variables never imported from the dev shell:

```lua
require("flk").ignored_variables["SHELL"] = false
```

`SHELL` is ignored by default because `nix develop` points it at nixpkgs'
non-interactive bash, which breaks `:terminal`.

See [flk.txt](doc/flk.txt) for the full reference.
